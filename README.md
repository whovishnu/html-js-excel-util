# HTML JavaScript Excel Utility

A browser-based utility for uploading multiple Excel files, merging their data,
selecting columns, and downloading the result. All processing happens locally in
the browser using SheetJS.

## Live demo

**[Open the Excel Utility](https://whovishnu.github.io/html-js-excel-util/)**

## Features

- Upload multiple `.xlsx` files
- Detect columns across uploaded files
- Select the columns to include
- Merge rows into a single workbook
- Download the processed Excel file
- Process files locally without uploading them to a server

## Usage

1. Open the [live application](https://whovishnu.github.io/html-js-excel-util/).
2. Select one or more Excel files.
3. Choose the columns you want to include.
4. Download the merged output file.

## Run locally

This is a static web application. Clone the repository and open `index.html` in
a browser, or serve the directory with any static web server.

## Versions

The repository includes earlier experiments in `v1.html`, `v2.html`, and
`v3.html`. The deployed application uses `v4.html`.
